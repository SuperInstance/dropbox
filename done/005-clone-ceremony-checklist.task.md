# 005 — The clone ceremony: one-page checklist

**Thesis:** #10 clone-as-data-full-state ("The clone ceremony")

**The work:** Philosophy becomes procedure when it fits on one page. Write the concrete clone ceremony checklist:
1. Freeze loops (what's running, how to stop each).
2. Snapshot files — committed AND uncommitted.
3. Capture ledger position (which entry is the tip).
4. Re-issue credentials (never copy them).
5. Stamp the clock delta (source time vs dest time).
6. Name the new entity in the ledger (the fork announcement).

**Done looks like:** A `CLONE-CEREMONY.md` (one page, checkable boxes) committed to `SuperInstance/muse-workspace` under `ideas/` or a new `procedures/` dir. Then actually perform it once — clone something small (one Oracle crab) following only the checklist, and note every place the checklist was wrong or incomplete. Fix the checklist from the notes.

**Size:** 1–2 hours.
